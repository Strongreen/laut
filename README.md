## ✨ Sobre

O **Laut** coloca a tradução onde você já está: em qualquer página, com qualquer texto, de qualquer idioma para outro. Sem abrir outra aba, sem copiar e colar em sites de tradução.

Foi criado por [Ströngreen](https://strongreen.com) e é lançado **de graça para a comunidade**.

## 🎯 Para quem é

| | |
|---|---|
| 📚 **Quem estuda idiomas** | Leia textos reais na língua que está aprendendo e confira a tradução na hora. |
| ♿ **Acessibilidade** | Reduz a barreira do idioma para quem precisa de apoio para ler e entender conteúdo. |
| 🌍 **Quem navega o mundo todo** | Notícias, documentação e fóruns em qualquer língua deixam de ser um problema. |

## 📦 Instalação

### Pela Chrome Web Store (recomendado)

1. Abra a página do Laut na [Chrome Web Store](#) <!-- TODO: colocar o link quando publicado -->
2. Clique em **Usar no Chrome**
3. Fixe o ícone 📌 do Laut na barra de extensões

## 🕹️ Como usar

1. Clique no ícone do Laut na barra do Chrome
2. Escolha o idioma de destino
3. Insira ou selecione o texto e veja a tradução
